Two things vary by role — which to use when

HeaderStep flow (a numbered sequence you move through): 40px circle Back, X to close, “Step x of n”.   Add / edit modal (one screen you open, change and confirm): Cancel left, Done right, title centred.
Primary buttonColour #7FA187 always.   Flow CTA — full-width, pinned to the bottom, advances or commits a flow: 56 high, 14 radius, 17px.   Inline action on a settings, edit or list screen (Save, Done, Add): 52 high, 12 radius, 16px.

Value in plain text, muted chevron. The problem: this is the iOS drill-in look, so it reads as “go to a screen” or just a label — not “tap to change”.

The value is in the link colour, so it reads as a control. “Not answered” becomes a tappable + Add. Smallest change, still iOS-native.

A pencil instead of the chevron spells out “edit”. Clearest, but a second icon style to maintain, and the chevron still fits the drill-in rows.
