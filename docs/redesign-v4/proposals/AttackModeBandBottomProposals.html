"Attack mode on" above the bottom nav — four directions

What's built now (95bb96f) puts the band across the top of the hero. At attack mode's 20px text it wraps to two lines and pushes the headline down, which makes the top of the screen heavy at exactly the moment it should be quietest. These move it to the bottom, near the thumb and the + button. Off stays as built: the small "Attack mode" pill at the top of the hero.

All frames are 375×812 with attack mode on. In each one the text inside the band is fixed in size and stays on one line (as BottomNav fixes its own), with no icon — the pill shows the icon when it's off. The dashed line marks where Today's content now has to stop scrolling.

AFloating band above the nav, Today only

The built band, moved: a rounded card, 16px in from each side, floating just above the + button. One line. It appears only on Today; on the other tabs attack mode is turned off from Settings, as now.

Today

For

  • Smallest change from what's built — same band, new place.
  • The hero goes back to how it looks with attack mode off.

Against

  • Floats over content — Today needs about 60px more bottom space while it's on.
  • Only a way out on Today.
  • Covers roughly a card's height of the screen you're reading.

CA small chip over the + button

Lighter than a band: a centred chip, "Attack mode on" with a small "Turn off" inside it, sitting above the + button. Works on Today only or on every tab.

Today

For

  • Least weight anywhere on the screen.
  • Covers the least content.

Against

  • "Turn off" inside a chip is a 34px button — needs an invisible 44px tap area.
  • Sits right over the +, the busiest tap spot; mis-taps either way.
  • Fixed text in a chip has the least room at 150% text size.

DA strip fixed to the top of the nav

Not floating: a full-width strip that is part of the nav itself, edge to edge, with the + button settling into the nav instead of rising above it. Reads as "the app is in a mode" rather than as a card. Works on Today only or on every tab.

Today

For

  • Calmest: no floating card and no rounded shape over the content.
  • Content stops above it cleanly — the nav just gets taller.
  • Same idea as iOS's call or hotspot bar, which people know as "a mode is on".

Against

  • The + loses its raised position while it's on (it would cover the strip's text) — a visible change to the nav.
  • The nav gets 56px taller, so less of each screen shows.

My pick: D, on every tab

It takes the weight off the top without putting a floating card over what you're reading, and it looks like part of the app's frame rather than one more thing on the page. On every tab, because once it's part of the nav it would look odd if it disappeared when you switched tabs. If you'd rather not change the nav, A is the closest to what's built.
